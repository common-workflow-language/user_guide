1.1. Inicio rápido#

Esta sección le mostrará un breve resumen de lo que es CWL, y dónde puede aprender más sobre él. No se requieren conocimientos previos de CWL, pero debe sentirse cómodo siguiendo instrucciones para la línea de comandos.

1.1.1. «Hola Mundo»#

CWL es una forma de describir herramientas de línea de comandos y conectarlas entre sí para crear flujos de trabajo. Dado que CWL es una especificación y no un software específico, las herramientas y los flujos de trabajo descritos mediante CWL son portables en diversas plataformas compatibles con el estándar CWL.

Los documentos CWL se escriben en YAML (y/o JSON). El siguiente ejemplo muestra un simple flujo de trabajo CWL «Hola Mundo» anotado con comentarios. Tenga en cuenta que los comentarios empiezan por #:

hello_world.cwl#
cwlVersion: v1.2

# What type of CWL process we have in this document.
class: CommandLineTool
# This CommandLineTool executes the linux "echo" command-line tool.
baseCommand: echo

# The inputs for this process.
inputs:
  message:
    type: string
    # A default value that can be overridden, e.g. --message "Hola mundo"
    default: "Hello World"
    # Bind this message value as an argument to "echo".
    inputBinding:
      position: 1
outputs: []

El ejemplo anterior es sólo una envoltura para la herramienta de línea de comandos echo. Ejecutar el flujo de trabajo anterior con los valores de entrada por defecto producirá el mismo resultado que la línea de comandos echo "Hola Mundo".

Nota

En CWL, hay una distinción entre una herramienta de línea de comandos y un flujo de trabajo. Pero en aras de la simplicidad, vamos a utilizar el término «flujo de trabajo» aquí. Aprenderás más sobre esto en la sección conceptos básicos.

1.1.2. Instalación de un ejecutante CWL#

cwltool es una implementación de la especificación CWL. También es el CWL Reference Runner para la especificación, y es compatible con la última versión de la especificación: v1.2. Puedes instalar cwltool usando pip:

Instalando cwltool con pip.#
$ pip install cwltool

Nota

Si la instalación de cwltool mediante el comando pip no le funciona, la sección prerequisites contiene otras formas de instalar cwltool y una lista más detallada del software y las librerías utilizadas para seguir el resto de esta guía de usuario.

1.1.3. Ejecutando «Hola Mundo»#

El uso de la línea de comando cwltool ejecutable básicamente es cwltool [OPTIONS] [CWL_DOCUMENT] [INPUTS_OBJECT]. Puede ejecutar el flujo de trabajo hello_world.cwl sin especificar ninguna opción:

Ejecutando hello_world.cwl con cwltool.#
$ cwltool hello_world.cwl
INFO /opt/hostedtoolcache/Python/3.14.7/x64/bin/cwltool 3.2.20260720092025
INFO Resolved 'hello_world.cwl' to 'file:///home/runner/work/user_guide/user_guide/src/_includes/cwl/hello_world.cwl'
INFO [job hello_world.cwl] /tmp/fobsxrde$ echo \
    'Hello World'
Hello World
INFO [job hello_world.cwl] completed success
{}INFO Final process status is success

O puede sobrescribir el valor por defecto del parámetro de entrada message, similar a como cambiaría el argumento del comando base echo:

Ejecutando hello_world.cwl con cwltool pasando un parámetro de entrada.#
$ cwltool hello_world.cwl --message="Hola mundo"
INFO /opt/hostedtoolcache/Python/3.14.7/x64/bin/cwltool 3.2.20260720092025
INFO Resolved 'hello_world.cwl' to 'file:///home/runner/work/user_guide/user_guide/src/_includes/cwl/hello_world.cwl'
INFO [job hello_world.cwl] /tmp/3d5top7n$ echo \
    'Hola mundo'
Hola mundo
INFO [job hello_world.cwl] completed success
{}INFO Final process status is success

Otra forma de pasar valores a los parámetros de entrada de su flujo de trabajo es a través de un Inputs Object. Se trata de un archivo que contiene los campos de entrada con sus valores correspondientes. El archivo de Objetos de Entrada se puede escribir en JSON o YAML. Por ejemplo:

hello_world-job.json#
{
  "message": "こんにちは世界"
}

Ahora puede utilizar este archivo Objeto de Entrada para ejecutar el flujo de trabajo «Hola Mundo»:

Pasar un archivo de Objetos de Entrada a cwltool.#
$ cwltool hello_world.cwl hello_world-job.json
INFO /opt/hostedtoolcache/Python/3.14.7/x64/bin/cwltool 3.2.20260720092025
INFO Resolved 'hello_world.cwl' to 'file:///home/runner/work/user_guide/user_guide/src/_includes/cwl/hello_world.cwl'
INFO [job hello_world.cwl] /tmp/q_54bp2t$ echo \
    こんにちは世界
こんにちは世界
INFO [job hello_world.cwl] completed success
{}INFO Final process status is success

Nota

Utilizamos un nombre de archivo similar para el flujo de trabajo y para los archivos de Objetos de Entrada. El sufijo -job.json es muy común en los archivos Objetos de Entrada, pero no es un requisito. Puede elegir cualquier nombre para sus flujos de trabajo y archivos de Objetos de Entrada.
